# CDFI LENDING IMPACT ON ENTREPRENEURSHIP
## Data Construction Pipeline - Setup Guide

**Author:** Spencer Sween  
**Updated:** January 2026

---

## Overview

This project analyzes the impact of Community Development Financial Institution (CDFI) lending on entrepreneurship outcomes at the ZIP code level from 1988-2016. The analysis uses data from multiple sources including CDFI transaction records, entrepreneurship data from the Startup Cartography Project, census crosswalks, and various demographic and economic covariates.

## Quick Start Guide

### Step 1: Set Up Directory Structure

1. Open `cdfi_analysis_master.do` in Stata
2. Navigate to **SECTION 0: PROJECT SETUP** (lines ~40-200)
3. Update the paths:
   ```stata
   global OLD_PROJECT "/Users/spencersween/Dropbox/CDFI Project"
   global NEW_PROJECT "/Users/[YOUR_USERNAME]/[YOUR_PATH]/CDFI_Clean_Project"
   ```
4. **Uncomment the entire Section 0** by removing the `/*` at the beginning and `*/` at the end
5. Run Section 0 once to:
   - Create all necessary directories
   - Copy all raw data files to organized locations
   - Generate this README file

### Step 2: Update Working Directory

After Section 0 completes successfully:

1. Navigate to line ~220 in the do-file
2. Update the working directory:
   ```stata
   cd "/Users/[YOUR_USERNAME]/[YOUR_PATH]/CDFI_Clean_Project"
   ```
3. **Re-comment Section 0** to prevent accidental re-runs

### Step 3: Run the Pipeline

1. Uncomment **Section 1.1** if you need to rebuild raw CDFI data from scratch
2. Run the entire do-file to construct the final analysis dataset
3. Find your final dataset at: `data/analysis/final_analysis_dataset.dta`

## Data Sources

### Primary Data Sources

1. **CDFI Transaction Level Reports (TLR)**
   - Source: CDFI Fund, U.S. Department of Treasury
   - Coverage: FY2003-2021
   - Files: `releaseTLR_fy03_15(1-5of5).csv`, `releaseTLR_fy18.csv`, etc.
   - Description: Transaction-level records of CDFI business lending activities

2. **Startup Cartography Project**
   - Source: Andrews et al. (Academic Dataset)
   - File: `Entrepreneurship_by_ZIP_Code_academic.dta`
   - Description: ZIP-level entrepreneurship outcomes including startup formation rates, growth, and quality indices

3. **Geographic Crosswalks**
   - NHGIS Census Tract 2000-2010 Crosswalk (`nhgis_tr2000_tr2010.csv`)
   - HUD-USPS Tract-ZIP Crosswalk Q1 2013 (`tract_zip_032013.xlsx`)
   - HUD-USPS ZIP-County Crosswalk Q1 2013 (`zip_county_032013.xlsx`)
   - ZIP-ZCTA Crosswalk (`ZIP Code to ZCTA Crosswalk.xlsx`)

4. **Demographic Covariates**
   - Source: ACS 2008-2012 (ICPSR 38528)
   - File: `38528-0003-Data.dta`
   - Description: Demographic and socioeconomic variables at ZCTA level

5. **Bank Structure Data**
   - Source: NaNDA (National Neighborhood Data Archive)
   - File: `bank_structure.dta`
   - Description: Time-varying banking presence and population

6. **Land Cover Data**
   - File: `landcover.dta`
   - Description: Land use patterns and development intensity

7. **Labor Market Data**
   - Source: County Business Patterns
   - File: `zbp_1994_2016_by_zip.csv`
   - Coverage: 1994-2016
   - Description: Establishments, employment, and wages at ZIP level

## Pipeline Overview

### Section 1: Raw Data Import
- Imports and combines CDFI TLR data from multiple fiscal years
- Extracts valid ZIP codes from SCP entrepreneurship data

### Section 2: Geographic Crosswalks
- Creates mappings between:
  - Census tracts (2000 → 2010)
  - Census tracts → ZIP codes
  - ZIP codes → Counties
  - ZIP codes → ZCTAs

### Section 3: CDFI Treatment Variable Construction
- **County-level treatment timing:** First year of CDFI activity per county
- **ZIP-level intensity:** Count of CDFI loans per ZIP-year
- **Final treatment assignment:** Combines county emergence and ZIP intensity

### Section 4: Control Variables
- ACS demographics (2008-2012 averages)
- Time-varying population, banking presence, and land cover
- Labor market indicators (establishments, employment, wages)

### Section 5: Final Analysis Dataset
- Merges entrepreneurship outcomes with treatment and controls
- Creates balanced panel (ZIP-year level, 1988-2016)
- Generates outcome variables and per-capita measures
- Creates year-specific baseline variables for DiD/event studies
- Winsorizes outcomes and drops low-population areas

## Key Variables in Final Dataset

### Identifiers
- `id`: ZIP code identifier
- `time`: Year
- `group`: Treatment cohort (year of first CDFI activity, 0 if never treated)
- `cluster_zcta`, `cluster_county`, `cluster_state`: Clustering variables

### Treatment Indicators
- `i_treat`: Ever-treated indicator (=1 if G_final > 0)
- `i_treat_post`: Post-treatment indicator (=1 if year >= G_final)
- `G_final`: Treatment year (earliest of county or ZIP intensity)
- `G_county`: County-level treatment year
- `G_intensity`: ZIP-level first observed activity year

### Outcome Variables

**Entrepreneurship:**
- `y_sfr`: Startup formation rate (count)
- `y_sfr_pc`: Startups per 1,000 population
- `y_eqi`: Entrepreneurial quality index
- `y_growth`: Business growth/expansions (count)
- `y_growth_pc`: Growth per 1,000 population
- `y_recpi_pc`: Revenue-weighted startups per 1,000 pop (sfr * eqi / pop)

**Labor Market:**
- `y_logwage`: Log average wage
- `y_empop`: Employment-to-population ratio (%)
- `y_est_pc`: Establishments per 1,000 population
- `y_cdfi_pc`: CDFI loans per 1,000 population

### Control Variables

**Time-Invariant (X_ prefix):**
- `X_aland10`: Log land area (2010)
- `X_totpop08_12`: Log population (ACS 2008-2012)
- `X_state1` - `X_state[N]`: State fixed effects
- Various demographic variables from ACS

**Time-Varying (V_ prefix):**
- `V_totpop`: Log population
- `V_lenders_pc`: Bank lenders per 1,000 population
- `V_areadev`: Share of developed land area

**Year-Specific (Wy_ prefix):**
- `Wy_y_sfr_pc_YYYY`: Outcome in year YYYY
- `Wy_y_eqi_YYYY`: Outcome in year YYYY
- [Created for years 1988-2016]

## Sample Restrictions

The final dataset includes only:
- ZIP codes present in Startup Cartography Project data
- ZCTAs with population > 100 in both current census and ACS 2008-2012
- ZIPs with non-zero wage data from County Business Patterns
- Outcomes are winsorized at 1st and 99th percentiles by year

**Sample period:** 1988-2016 (full panel)  
**Analysis period:** 1996-2014 (CDFI program active)

## Troubleshooting

**"File not found" errors:**
- Verify Section 0 completed successfully
- Check that all source files exist in old project directory
- Confirm working directory path is correct

**"Variable not found" errors:**
- Ensure all intermediate files were created
- Check that previous sections completed without errors
- Verify dataset merges completed successfully

**Memory errors:**
- Increase Stata memory: `set maxvar 32000`
- Use `clear all` between sections if needed
- Consider running on machine with more RAM
